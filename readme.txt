Deploy on Netlify:
1. Go to https://app.netlify.com/drop
2. Drag this whole folder (or the zip) onto the page.
3. Netlify gives you a live link. Rename it under Site configuration > Change site name (e.g. aakash-saumya.netlify.app).
4. For a WhatsApp link preview, open index.html and change og.jpg in the og:image line to https://YOUR-SITE.netlify.app/og.jpg, then redeploy.
